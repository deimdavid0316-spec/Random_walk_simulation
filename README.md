# Random Walk Simulation Project in Python
## Dávid Deim (CW2DKK) & Henrieta Horváth (CWKQJB)
### Date: 2026.10.21
## Description of the project
The main goal of the project is to build a program that can accurately simulate and visualize random walking and Brownian motion in 2D and 3D processes, and to analyze the statistical properties of the resulting motion. For a successful application of the idea, numerical simulations and analytical resulst are combined, so the expected distance from the origin is compared with the theoritical scaling. The understanding of probability distributions and kernel density estimations for fitting is also required for an effective implementation. The project is written in Python, on the Github platform.
